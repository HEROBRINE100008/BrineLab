Clasificacion de Conjuntos

- Finitos 
Ej: 
Lv = {x|x las vocales}
Lv = {a,e,i,o,u}

- Infinito
Ej:
N = {1,2,3,4...}
- Vacio (∅), {∅}, ∅

- Unitario
Ej:
A = {2}

- Universal

- Equivalentes (Comparar)
A = {a,b,c,d,e}
B = {1,2,3,4,5}

- Disyuntivos
A = {1,2,3}
B = {a,b,c,d}

- Iguales
A = {1,2,3,4}
B = {4,3,2,1}
C = {2,3,4,1}

- Congruentes (Numericos)
A = {2,4,6,8}
B = {3,5,7,9}
C = {20,22,24,26}

- No Congruentes
A = {3,5,9}
B = {4,5,6}

- Homogéneo
A = {1,2,3,4,5}
B = {6,7,8,9,10}

- Heterogéneas
C = {moneda,$,carro,naranja}
